### 🔬 Featured projects

| Project | What it is |
|:--|:--|
| [**uc3m-tfm-elf-malware-classification**](https://github.com/fernandoalonsoo/uc3m-tfm-elf-malware-classification) | MSc thesis (grade 10/10, honours proposed). Classification of IoT botnet malware families (Mirai, Gafgyt, Hajime, Tsunami) in Linux ELF binaries: 2,311-sample dataset, static features (LIEF) and dynamic features (KVM sandbox with strace, auditd and Suricata), LightGBM classifier explained with SHAP.
